## 1. 五個討論點

### 1.1 槽位介面完全對上，沒有隱藏的不匹配

AK21 精讀歸納出的四條介面 E1–E4，逐條核對 RNC-IBE 的 Def 6：

| 介面 | RNC-IBE 是否滿足 |
|---|---|
| E1 模糊化不可區分 | 是。即 real/ideal 兩世界不可區分 |
| E2 訊息無關生成 | 是。Sim₃(st₂, id\*) 不吃訊息 |
| E3 事後綁定金鑰 | 是。Sim₄(st₃, k)，需固定隨機性並附到 B、C 兩個 register |
| E4 後量子 | 視選哪個構造而定（見 1.4） |

結論：**介面層面沒有隱藏的不匹配**，風險只集中在零件（E4）與定義選擇（1.3 的 D-W1）。

### 1.2 Def 6 交出的是 msk，不是 sk_{id\*}——免費的更強定理

模擬器 `Sim₄(st₃, m*) → msk`，挑戰階段對手收到 (msk, ct\*)。這是承襲 HMNY21（ASIACRYPT 2021）NC-ABE 的設定。

對 W1 的意義：cloning game 的 reveal 階段可以把**整把 msk** 交給 B 和 C，歸約仍然模擬得出來。定理因此更強，且不花額外代價。

> 可寫進 abstract 的一句話：**即使金鑰機構的主金鑰事後全面洩漏，密文仍然不可複製。**

這也是 IBE 版相對 HKNY24 的 PKE 版真正多出來的東西。

### 1.3 D-W1：唯一被識別的技術硬點

`Sim₂(st₁, id) → sk_id` 是 **stateful** 的（回答金鑰查詢時會更新 st₂）。若定義允許 split 之後 B、C 各自查詢非挑戰身分的金鑰，歸約就需要「同一個 stateful 模擬器被兩條互不通訊的分支同時呼叫」。

三條出路：

1. 起步版只允許 split **前**查詢，把 split 後查詢當 open problem 誠實寫出；
2. **論證 1.2 已經解決它**——既然 B、C 手上有 msk̃，自己就能生任何身分的金鑰，不必回頭呼叫 Sim₂，狀態協調自動消失；
3. 要求槽位滿足「無狀態模擬」的加強版介面，再檢查 Thm 3 的構造是否恰好滿足。

**出路 2 看起來最有機會，且與 1.2 的決定互相加強。這是下一步該先驗證的命題**，也想請老師確認論證是否嚴謹。

### 1.4 後量子零件的實況：三個構造只有一個能用

| 構造 | 假設 | 身分空間 | 可用 |
|---|---|---|---|
| Thm 1（§5，dual system） | SXDH 雙線性 | 指數 | 否，非後量子 |
| **Thm 3（§6，relaxed）** | DDH 或 **LWE** | **多項式大小 T** | **是，唯一選項** |
| Thm 5（全文版） | iO + OWF | — | 否 |

代價：密文尺寸 poly(T, |m|, λ)，mpk/msk/sk 尺寸 poly(T, λ)。這正是後量子策略需要拍板的原因（見 2.2）。

### 1.5 主定理應該以 KEM 介面陳述

論文自己的 Thm 11 說明 RNC-IB-KEM ＋ OTP 即得 RNC-IBE。我們的構造其實只需要**封裝一把 k**，所以直接把槽換成 **RNC-IB-KEM** 可以跳過一層 OTP，密文更短。

建議：主定理以 RNC-IB-KEM 為介面陳述，RNC-IBE 版當 corollary。

## 2. 想請老師拍板的問題

### 2.1 「不要走混淆電路」的範圍（建議開場先問）

上次討論記下的是避開 **MM24 用的量子混淆電路（QGC）**，理由是純理論、沒有實作、開銷爆炸。W1 完全不碰 QGC，所以定案本身已經回應了這個意見。

但要確認範圍：RNC-IBE 的 §6（Thm 3，**唯一的後量子選項**）用的是**古典 Yao garbled circuit** ＋ batch encryption，每個身分 garble 一個 NCE.Enc 電路，共 T 個。

| 老師指的是 | 對 W1 的影響 |
|---|---|
| 量子混淆電路（QGC） | 無影響，W1 不用 |
| 不可區分混淆（iO） | 無影響，Thm 5/6 本來就排除 |
| **任何 garbled circuit（含古典 Yao）** | **§6 死掉，只剩自造 LWE 版一條路** |

> 問法：「老師，上次您說避開混淆電路，我想確認是指 MM24 的**量子**混淆電路，還是連古典的 Yao garbled circuit 也一併避開？因為我要用的 RNC-IBE 後量子版本，內部用了古典 garbled circuit。」

補充一個技術區分：**§6 的效能問題不是 garbled circuit 造成的**，是「多項式大小身分空間」——密文要塞 T 個 garbled circuit。古典 GC 從 OWF 就有、在 MPC 裡是實用元件。

### 2.2 後量子零件：poly-ID 起步 vs 自造 LWE 版

- **甲案**：第一條定理直接引用 Thm 3 (LWE)，把 poly-ID 寫進定理敘述，力氣放在定義與 D-W1。低風險、4–6 週可有完整定理，但審稿人會問「為什麼只有多項式個身分」。
- **乙案**：用 GPV／ABB 陷門＋可模糊化，自造指數身分空間的 selective-ID RNC-IBE 當論文技術核心。中高風險、8 週起跳，但同時填兩個空格、自帶護城河。

兩案不互斥：甲案的產出在乙案下原封不動可用。建議先做甲案的定義與定理陳述，乙案的一週試探平行進行。

### 2.3 cloning game 定義：split 後的金鑰查詢要不要進定義？

做進去是本路線相對 HKNY24 的**定義層貢獻**，但帶 1.3 的 D-W1 風險。

### 2.4 競速：要不要儘早掛 ePrint 佔位？

RNC-IBE 作者群 = NTT ＋ Goyal 產線；且 NC-ABE 這個概念本來就是 HMNY21 為了憑證刪除（量子應用）引入的——他們補量子應用的能力最強。

考慮把「定義＋poly-ID 版定理」寫成 note 先掛 ePrint。
